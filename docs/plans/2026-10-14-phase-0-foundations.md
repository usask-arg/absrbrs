**Goal:** Build the absrbrs repository foundations: a Rust workspace with the core crate's error type, the Python package skeleton, the Arb reference generator with Faddeeva reference data, the Faddeeva prototype that chooses the Fast-tier algorithm, a third-party licence register, the documentation site, and CI. **Architecture:** The layout copies the sibling project scatrs (`~/dev/scat-rs`), taken at the pinned commit `4793160`:

- a maturin-built Python package in `python/absrbrs/`;
- separate uv projects for the Arb reference generator (`reference/`) and the Faddeeva prototype (`prototypes/faddeeva/`).

The prototype measures candidate approximations of w(z) against Arb and searches region-switched composites for the cheapest one that meets the Fast-tier targets. That result is the decision input for phase 1a.

```rust
//! Error type shared by every absrbrs computation (spec §7.4).

/// Errors returned by absrbrs.
#[derive(Debug, Clone, PartialEq, thiserror::Error)]
#[non_exhaustive]
pub enum Error {
    /// An input is outside its valid range: a wavenumber grid that is not strictly increasing,
    /// a non-positive temperature, a NaN, a buffer of the wrong size, an output too large, ...
    #[error("invalid input: {0}")]
    InvalidInput(String),
    /// No partition function is available for an isotopologue.
    #[error("no partition function for molecule {molecule}, isotopologue {isotopologue}")]
    MissingPartitionFunction {
        /// HITRAN molecule number.
        molecule: u16,
        /// HITRAN isotopologue number (codes 0, A and B are 10, 11 and 12).
        isotopologue: u16,
    },
    /// A temperature is outside the range of a partition-function table.
    #[error(
        "temperature {temperature} K is outside the partition-function table of molecule \
         {molecule}, isotopologue {isotopologue}"
    )]
    OutsideTable {
        /// HITRAN molecule number.
        molecule: u16,
        /// HITRAN isotopologue number.
        isotopologue: u16,
        /// The temperature requested, in K.
        temperature: f64,
    },
    /// A record of a line file is malformed.
    #[error("line {line_number}: {message}")]
    Parse {
        /// One-based line number of the record in its file.
        line_number: usize,
        /// What is wrong with the record.
        message: String,
    },
    /// A file could not be read.
    #[error("cannot read {path}: {message}")]
    Io {
        /// The path, as given.
        path: String,
        /// The operating system's description of the failure.
        message: String,
    },
}

/// Result alias using [`Error`].
pub type Result<T> = core::result::Result<T, Error>;

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn messages_are_informative() {

        assert_eq!(
```

Create `tests/test_errors.py`:

```python
import pickle
import sys

import pytest

import absrbrs
from absrbrs._absrbrs import _testing


def test_hierarchy():
    assert issubclass(absrbrs.AbsrbrsError, Exception)
    for cls, std in (
        (absrbrs.InvalidInputError, ValueError),
        (absrbrs.MissingPartitionFunctionError, LookupError),
        (absrbrs.OutsideTableError, ValueError),
        (absrbrs.ParseError, ValueError),
    ):
        assert issubclass(cls, absrbrs.AbsrbrsError)
        assert issubclass(cls, std)
    assert absrbrs.errors.AbsrbrsError is absrbrs.AbsrbrsError


@pytest.mark.parametrize(
    ("kwargs", "cls", "message", "attributes"),
    [
        (
            {"variant": "InvalidInput", "message": "bad"},
            absrbrs.InvalidInputError,
            "invalid input: bad",
            {},
        ),
        (
            {"variant": "MissingPartitionFunction", "molecule": 2, "isotopologue": 11},
            absrbrs.MissingPartitionFunctionError,
            "no partition function for molecule 2, isotopologue 11",
            {"molecule": 2, "isotopologue": 11},
        ),
        (
            {"variant": "OutsideTable", "molecule": 2, "isotopologue": 1, "temperature": 6000.5},
            absrbrs.OutsideTableError,
            "temperature 6000.5 K is outside the partition-function table of molecule 2, "
            "isotopologue 1",
            {"molecule": 2, "isotopologue": 1, "temperature": 6000.5},
        ),
        (
            {"variant": "Parse", "line_number": 17, "message": "bad width"},
            absrbrs.ParseError,
            "line 17: bad width",
            {"line_number": 17},
        ),
    ],
)
def test_core_errors_map_to_their_classes(kwargs, cls, message, attributes):
    with pytest.raises(cls) as info:
        _testing.raise_core_error(**kwargs)
    assert type(info.value) is cls
    assert str(info.value) == message
    for name, value in attributes.items():
        assert getattr(info.value, name) == value


def test_io_errors_are_oserrors():
    with pytest.raises(OSError, match=r"^cannot read CO2\.par: No such file$"):
        _testing.raise_core_error("Io", path="CO2.par", message="No such file")


def test_unknown_variant_is_rejected():
    with pytest.raises(ValueError, match="unknown absrbrs::Error variant"):
        _testing.raise_core_error("Nope")


def test_falls_back_to_runtime_error_when_the_classes_cannot_be_imported(monkeypatch):
    monkeypatch.setitem(sys.modules, "absrbrs.errors", None)
    with pytest.raises(RuntimeError, match="invalid input: bad") as info:
        _testing.raise_core_error("InvalidInput", message="bad")
    assert isinstance(info.value.__cause__, ImportError)


@pytest.mark.parametrize(
    "err",
    [
        absrbrs.MissingPartitionFunctionError("m", 2, 11),
        absrbrs.OutsideTableError("m", 2, 1, 7000.0),
        absrbrs.ParseError("m", 3),
    ],
)
def test_errors_pickle_with_their_attributes(err):
    back = pickle.loads(pickle.dumps(err))
    assert type(back) is type(err)
    assert str(back) == str(err)
    assert vars(back) == vars(err)
```

```rust
//! Conversion of `absrbrs::Error` into the exception classes defined in `absrbrs.errors`.

use pyo3::exceptions::{PyException, PyOSError, PyRuntimeError};
use pyo3::prelude::*;

/// The matching `absrbrs.errors` exception for a core error.
///
/// The message is the error's `Display` text, and the structured fields of a variant become
/// attributes of the exception. `Io` maps to the built-in `OSError`. Variants added to the
/// non-exhaustive `absrbrs::Error` later map to `AbsrbrsError` until they get a class of their
/// own. If building the exception fails with an `Exception` (say `absrbrs.errors` cannot be
/// imported), the result is a `RuntimeError` with the core message, caused by that exception;
/// any other failure (`KeyboardInterrupt`, ...) is returned unchanged.
pub fn to_pyerr(py: Python<'_>, err: absrbrs::Error) -> PyErr {
    let message = err.to_string();
    if let absrbrs::Error::Io { .. } = err {
        return PyOSError::new_err(message);
    }
    let build = || -> PyResult<PyErr> {
        let module = py.import("absrbrs.errors")?;
        let instance = match &err {
            absrbrs::Error::InvalidInput(_) => module
                .getattr("InvalidInputError")?
                .call1((message.as_str(),))?,
            absrbrs::Error::MissingPartitionFunction {
                molecule,
                isotopologue,
            } => module.getattr("MissingPartitionFunctionError")?.call1((
                message.as_str(),
                *molecule,
                *isotopologue,
            ))?,
            absrbrs::Error::OutsideTable {
                molecule,
                isotopologue,
                temperature,
            } => module.getattr("OutsideTableError")?.call1((
                message.as_str(),
                *molecule,
                *isotopologue,
                *temperature,
            ))?,
            absrbrs::Error::Parse { line_number, .. } => module
                .getattr("ParseError")?
                .call1((message.as_str(), *line_number))?,
            _ => module.getattr("AbsrbrsError")?.call1((message.as_str(),))?,
        };
        Ok(PyErr::from_value(instance))
    };
    build().unwrap_or_else(|failure| {
        if !failure.is_instance_of::<PyException>(py) {
            return failure;
        }
        let e = PyRuntimeError::new_err(message);
        e.set_cause(py, Some(failure));
        e
    })
}
```

```rust
//! Hooks for the Python tests (`tests/*.py`), in the submodule `absrbrs._absrbrs._testing`; not
//! part of the absrbrs API.

use pyo3::exceptions::PyValueError;
use pyo3::prelude::*;

use crate::errors::to_pyerr;

/// Name under which [`register`] puts the submodule in `sys.modules`.
const NAME: &str = "absrbrs._absrbrs._testing";

/// Adds the `_testing` submodule to `parent` (the extension module).
///
/// It is set as an attribute rather than with `add_submodule`, which would also list it in the
/// parent's `__all__`; and it is put in `sys.modules`, so that `import absrbrs._absrbrs._testing`
/// works too (an extension's submodules are otherwise reachable only as attributes).
pub fn register(parent: &Bound<'_, PyModule>) -> PyResult<()> {
    let py = parent.py();
    let module = PyModule::new(py, NAME)?;
    module.add_function(wrap_pyfunction!(raise_core_error, &module)?)?;
    parent.setattr("_testing", &module)?;
    py.import("sys")?
        .getattr("modules")?
        .set_item(NAME, &module)?;
    Ok(())
}

/// For tests only: raises the exception that the core error `variant` maps to, to test
/// [`to_pyerr`]. Not part of the absrbrs API.
///
/// `variant` names an `absrbrs::Error` variant; the other arguments are its fields (each
/// variant uses the ones it has).
#[pyfunction]
#[pyo3(signature = (
    variant, message = "", molecule = 0, isotopologue = 0, temperature = 0.0, line_number = 0,
    path = ""
))]
#[allow(clippy::too_many_arguments)]
pub fn raise_core_error(
    py: Python<'_>,
    variant: &str,
    message: &str,
    molecule: u16,
    isotopologue: u16,
    temperature: f64,
    line_number: usize,
    path: &str,
) -> PyResult<()> {
    let err = match variant {
        "InvalidInput" => absrbrs::Error::InvalidInput(message.into()),
        "MissingPartitionFunction" => absrbrs::Error::MissingPartitionFunction {
            molecule,
            isotopologue,
        },
        "OutsideTable" => absrbrs::Error::OutsideTable {
            molecule,
            isotopologue,
            temperature,
        },
        "Parse" => absrbrs::Error::Parse {
            line_number,
            message: message.into(),
        },
        "Io" => absrbrs::Error::Io {
            path: path.into(),
            message: message.into(),
        },
        _ => {
            return Err(PyValueError::new_err(format!(
                "unknown absrbrs::Error variant {variant:?}"
            )));
        }
    };
    Err(to_pyerr(py, err))
}
```

```python
"""Exception hierarchy raised by absrbrs.

Every absrbrs-specific failure is an :class:`AbsrbrsError`:

* :class:`InvalidInputError` (also a :class:`ValueError`): an argument has the right type but
  a value outside its valid range, including the documented size limits.
* :class:`MissingPartitionFunctionError` (also a :class:`LookupError`): no partition function
  is available for an isotopologue in the line list.
* :class:`OutsideTableError` (also a :class:`ValueError`): a temperature is outside the range
  of a partition-function table.
* :class:`ParseError` (also a :class:`ValueError`): a record of a line file is malformed.

A file that cannot be read raises the built-in :class:`OSError`.
"""

from __future__ import annotations

__all__ = [
    "AbsrbrsError",
    "InvalidInputError",
    "MissingPartitionFunctionError",
    "OutsideTableError",
    "ParseError",
]


class AbsrbrsError(Exception):
    """Base class for every error raised by absrbrs."""


class InvalidInputError(AbsrbrsError, ValueError):
    """An input is outside its valid range."""


class MissingPartitionFunctionError(AbsrbrsError, LookupError):
    """No partition function is available for an isotopologue.

    Parameters
    ----------
    message : str
        Description of the failure.
    molecule : int, optional
        HITRAN molecule number.
    isotopologue : int, optional
        HITRAN isotopologue number.
    """

    def __init__(
        self, message: str, molecule: int | None = None, isotopologue: int | None = None
    ) -> None:
        super().__init__(message)
        self.molecule = molecule
        self.isotopologue = isotopologue


class OutsideTableError(AbsrbrsError, ValueError):
    """A temperature is outside the range of a partition-function table.

    Parameters
    ----------
    message : str
        Description of the failure.
    molecule : int, optional
        HITRAN molecule number.
    isotopologue : int, optional
        HITRAN isotopologue number.
    temperature : float, optional
        The temperature requested, in K.
    """

    def __init__(
        self,
        message: str,
        molecule: int | None = None,
        isotopologue: int | None = None,
        temperature: float | None = None,
    ) -> None:
        super().__init__(message)
        self.molecule = molecule
        self.isotopologue = isotopologue
        self.temperature = temperature


class ParseError(AbsrbrsError, ValueError):
    """A record of a line file is malformed.

    Parameters
    ----------
    message : str
        Description of the failure.
    line_number : int, optional
        One-based line number of the record in its file.
    """

    def __init__(self, message: str, line_number: int | None = None) -> None:
        super().__init__(message)
        self.line_number = line_number
```

```markdown
# absrbrs reference generator

Independent ground truth for absrbrs tests, computed with Arb ball arithmetic through
[python-flint](https://python-flint.readthedocs.io). It does not import absrbrs.

    uv run --directory reference python -m absrbrs_reference generate            # all files
    uv run --directory reference python -m absrbrs_reference generate --only faddeeva
    uv run --directory reference python -m pytest

The record format is that of the sibling project scatrs. Each value is stored as three doubles
`hi`/`lo`/`lo2` (`hi` is the double nearest to the value, `hi + lo` a normalised double-double
and `lo2` the double nearest to the rest, about 160 bits in all), a decimal string `dec` (up to
25 significant digits, fewer when the ball is wider), and a rigorous error bound `err` on
|true − (hi + lo + lo2)|. `label` is `certified` when every source of error is rigorously
bounded, otherwise `high-precision`.

`data/manifest.json` records, for each file, the generator, the working precision, the
python-flint and FLINT versions and the SHA-256 of the file. python-flint is pinned exactly:
CI regenerates every file and fails on any difference from the committed bytes.

| File | Contents |
|---|---|
| `faddeeva.jsonl` | w(z) = exp(−z²) erfc(−iz) and w′(z) on the grid of spec §6.2: 124 values of x from 0 to 1e8 and 74 values of y from 0 to 1e6 |

Generators draw their inputs without the platform's maths library (use `nearest_pow10` from
`absrbrs_reference/records.py` instead of `10.0 ** u`), so the data are the same bytes on every
platform; `tests/test_portable_inputs.py` enforces this.
```

```python
"""The Faddeeva generator: known values, the zeros at x = 0, an independent check of w′, the
grid of spec §6.2 and the record layout."""

from flint import acb, arb, ctx

from absrbrs_reference.generators import faddeeva


def close(v: arb, expected: float, rel: float = 2.0**-52) -> bool:
    return abs(float(v.mid()) - expected) <= rel * abs(expected)


def test_known_values():
    w, dw, _ = faddeeva.w_and_derivative(0.0, 0.0)
    assert w.real == 1 and w.imag == 0 and dw.real == 0
    assert close(dw.imag, 1.1283791670955126)  # 2/√π
    w, _, _ = faddeeva.w_and_derivative(0.0, 1.0)
    assert close(w.real, 0.42758357615580700)  # erfcx(1)
    w, _, _ = faddeeva.w_and_derivative(1.0, 0.0)
    assert close(w.real, 0.36787944117144233)  # exp(−1)
    assert close(w.imag, 0.6071577058413937)  # (2/√π) D(1), D Dawson's integral


def test_w_is_real_on_the_imaginary_axis():
    w, dw, _ = faddeeva.w_and_derivative(0.0, 2.0)
    assert w.imag == 0 and dw.real == 0


def test_derivative_agrees_with_an_arb_central_difference():
    def w_at(z: acb) -> acb:
        return (-(z * z)).exp() * (-acb(0, 1) * z).erfc()

    for x, y in [(1.5, 0.25), (20.0, 1e-20), (1e6, 1.0)]:
        _, dw, _ = faddeeva.w_and_derivative(x, y)
        with ctx.workprec(1024):
            h = arb(2) ** -150
            z = acb(x, y)
            fd = (w_at(z + h) - w_at(z - h)) / (2 * h)
            assert abs(fd - dw) <= abs(dw) * arb(2) ** -70


def test_grid():
    xs, ys = faddeeva.x_grid(), faddeeva.y_grid()
    assert len(xs) == 124 and xs == sorted(set(xs))
    assert xs[0] == 0.0 and xs[-1] == 1e8 and 1e-8 in xs and 30.0 in xs
    assert len(ys) == 74
    assert ys[0] == 0.0 and ys[1] == 1e-30 and ys[-1] == 1e6


def test_record_layout():
    precision, records = faddeeva.generate(xs=[0.0, 1.0], ys=[0.0, 1.0])
    assert precision >= faddeeva.START_BITS
    assert [r["case"] for r in records] == ["y=0.0", "y=1.0"]
    for r in records:
        assert r["generator"] == "faddeeva" and r["label"] == "certified"
        assert r["inputs"]["x"] == [0.0, 1.0]
        assert set(r["outputs"]) == {"w_re", "w_im", "dw_re", "dw_im"}
        assert all(len(v["hi"]) == 2 for v in r["outputs"].values())
```

Create `reference/absrbrs_reference/generators/faddeeva.py`:

```python
"""The Faddeeva function w(z) = exp(−z²) erfc(−iz) and its derivative, on the validation grid.

One record per y value (case ``y=<repr(y)>``): inputs ``x`` (doubles ≥ 0, increasing) and ``y``
(a double ≥ 0); outputs ``w_re``, ``w_im``, ``dw_re`` and ``dw_im`` at each x. Negative x follow
from w(−x + iy) = conj(w(x + iy)) and are not stored.

w′(z) = −2z w(z) + 2i/√π is formed in Arb, where the cancellation this identity suffers in
floating point (about |z|² relative) only costs working precision. Each point is recomputed
at doubling precision until every stored component is known to 2^-80 relative (``TARGET_BITS``).
At x = 0, w(iy) is real, so Im w and Re w′ are exactly zero; they are stored as exact zeros.

The grid (spec §6.2): x ∈ {0, 0.5, …, 30} or {10^(k/4) : |k| ≤ 32}, 1e-8 to 1e8; y ∈ {0} or
{10^(k/2) : −60 ≤ k ≤ 12}, 1e-30 to 1e6.
"""

from __future__ import annotations

from flint import acb, arb, ctx

from absrbrs_reference.records import nearest_pow10, record

TARGET_BITS = 80
START_BITS = 128
MAX_BITS = 16384


def x_grid() -> list[float]:
    """0, 0.5, …, 30 (exact) and 10^(k/4) for |k| ≤ 32, sorted and without duplicates."""
    linear = [k / 2 for k in range(61)]
    logs = [nearest_pow10(k / 4) for k in range(-32, 33)]
    return sorted(set(linear) | set(logs))


def y_grid() -> list[float]:
    """0 and 10^(k/2) for −60 ≤ k ≤ 12."""
    return [0.0, *(nearest_pow10(k / 2) for k in range(-60, 13))]


def _accurate(part: arb, scale: arb) -> bool:
    """Whether the ball ``part`` is known to TARGET_BITS relative to ``scale`` (> 0)."""
    return bool(part.rad() <= scale * arb(2) ** -TARGET_BITS)


def w_and_derivative(x: float, y: float) -> tuple[acb, acb, int]:
    """Arb balls for w(x + iy) and w′(x + iy), and the precision (bits) that achieved them.

    Re w is known to TARGET_BITS relative to itself (it is positive), Im w relative to |w|, and
    both parts of w′ relative to |w′|, the scales of the spec §6.2 metrics. Raises
    ``ArithmeticError`` if MAX_BITS is not enough.
    """
    bits = START_BITS
    while bits <= MAX_BITS:
        with ctx.workprec(bits):
            z = acb(x, y)
            w = (-(z * z)).exp() * (-acb(0, 1) * z).erfc()
            dw = -2 * z * w + 2 * acb(0, 1) / arb.pi().sqrt()
            if x == 0.0:
                w = acb(w.real, 0)
                dw = acb(0, dw.imag)
            w_scale, dw_scale = abs(w).mid(), abs(dw).mid()
            if (
                _accurate(w.real, abs(w.real.mid()))
                and (x == 0.0 or _accurate(w.imag, w_scale))
                and (x == 0.0 or _accurate(dw.real, dw_scale))
                and _accurate(dw.imag, dw_scale)
            ):
                return w, dw, bits
        bits *= 2
    raise ArithmeticError(f"w({x!r} + {y!r}i) not resolved to 2^-{TARGET_BITS} by {MAX_BITS} bits")


def generate(
    xs: list[float] | None = None, ys: list[float] | None = None
) -> tuple[int, list[dict]]:
    """Records for every y of ``ys`` (default `y_grid`) over the x of ``xs`` (default `x_grid`)."""
    xs = x_grid() if xs is None else xs
    ys = y_grid() if ys is None else ys
    records = []
    max_bits = START_BITS
    for y in ys:
        outputs: dict[str, list[arb]] = {"w_re": [], "w_im": [], "dw_re": [], "dw_im": []}
        for x in xs:
            w, dw, bits = w_and_derivative(x, y)
            max_bits = max(max_bits, bits)
            outputs["w_re"].append(w.real)
            outputs["w_im"].append(w.imag)
            outputs["dw_re"].append(dw.real)
            outputs["dw_im"].append(dw.imag)
        records.append(record("faddeeva", f"y={y!r}", {"x": xs, "y": y}, outputs))
    return max_bits, records
```

Background for the implementer:
- w(z) is the Faddeeva function, and the Voigt line shape is K = Re w(x + iy). Every candidate returns the derivative of its own formula, never w′ from the identity −2zw + 2i/√π, because that identity cancels catastrophically in the wings.
- The candidates are:
  - Weideman's rational approximation (SIAM J. Numer. Anal. 31, 1994), accurate near the origin;
  - the Laplace continued fraction (asymptotic, for large |z|; depth 1 is Humlíček's region-I formula);
  - exp(−z²) plus the continued fraction, for small y and moderate |x|;
  - a Taylor series in iy around the real axis, using Dawson's integral;
  - sasktran2's 8-pole J-pole approximation, as a baseline.

```python
"""Reference values of w and w′: the committed Arb grid, and a denser Arb map cached locally.

The dense map is not committed (it is about 140 000 points); ``dense()`` computes it once with
Arb, in parallel, and caches it in ``prototypes/faddeeva/.cache/dense.npz``.
"""

from __future__ import annotations

import json
from concurrent.futures import ProcessPoolExecutor
from pathlib import Path

import numpy as np
from flint import acb, arb, ctx
from numpy.typing import NDArray

Complex = NDArray[np.complex128]

PROTOTYPE = Path(__file__).resolve().parents[1]
REPO = PROTOTYPE.parents[1]
COMMITTED = REPO / "reference" / "data" / "faddeeva.jsonl"
CACHE = PROTOTYPE / ".cache" / "dense.npz"

#: Each component used by the metrics is known to this relative accuracy before rounding.
REL_BITS = 60


def complex_points(x: NDArray[np.float64], y: NDArray[np.float64]) -> Complex:
    """x + iy, formed exactly (no arithmetic on the parts)."""
    z = np.empty(np.broadcast(x, y).shape, dtype=np.complex128)
    z.real = x
    z.imag = y
    return z


def load_committed(path: Path = COMMITTED) -> tuple[Complex, Complex, Complex]:
    """The committed reference grid as flat arrays ``(z, w, dw)`` (the nearest doubles)."""
    zs, ws, dws = [], [], []
    for line in path.read_text("utf-8").splitlines():
        if not line.strip():
            continue
        r = json.loads(line)
        x = np.array(r["inputs"]["x"], dtype=np.float64)
        zs.append(complex_points(x, np.full_like(x, r["inputs"]["y"])))
        o = r["outputs"]
        ws.append(complex_points(np.array(o["w_re"]["hi"]), np.array(o["w_im"]["hi"])))
        dws.append(complex_points(np.array(o["dw_re"]["hi"]), np.array(o["dw_im"]["hi"])))
    return np.concatenate(zs), np.concatenate(ws), np.concatenate(dws)


def arb_w(x: float, y: float) -> tuple[float, float, float, float]:
    """(Re w, Im w, Re w′, Im w′) at x + iy, Re w to 2^-60 relative and each part of w′ to
    2^-60 |w′|, computed in Arb at increasing precision."""
    eps = arb(2) ** -REL_BITS
    prec = 128
    while prec <= 16384:
        with ctx.workprec(prec):
            z = acb(x, y)
            w = (-(z * z)).exp() * (-acb(0, 1) * z).erfc()
            dw = -2 * z * w + 2 * acb(0, 1) / arb.pi().sqrt()
            scale = abs(dw)
            ok = (
                w.real.rad() <= abs(w.real.mid()) * eps
                and dw.real.rad() <= scale.mid() * eps
                and dw.imag.rad() <= scale.mid() * eps
            )
            if ok:
                return (
                    float(w.real.mid()),
                    float(w.imag.mid()),
                    float(dw.real.mid()),
                    float(dw.imag.mid()),
                )
        prec *= 2
    raise ArithmeticError(f"w({x!r} + {y!r}i) did not reach 2^-{REL_BITS} by 16384 bits")


def _arb_pair(xy: tuple[float, float]) -> tuple[float, float, float, float]:
    return arb_w(*xy)


def dense_grid() -> Complex:
    """x ∈ {0, 1/32, …, 12} or {10^(k/16) : |k| ≤ 128}; y ∈ {0} or {10^(k/6) : −180 ≤ k ≤ 36}."""
    xs = np.unique(np.concatenate([np.arange(385) / 32.0, 10.0 ** (np.arange(-128, 129) / 16)]))
    ys = np.concatenate([[0.0], 10.0 ** (np.arange(-180, 37) / 6)])
    x, y = np.meshgrid(xs, ys)
    return complex_points(x.ravel(), y.ravel())


def compute(z: Complex, workers: int | None = None) -> tuple[Complex, Complex]:
    """Arb values ``(w, dw)`` at the points ``z``, in parallel."""
    pairs = list(zip(z.real.tolist(), z.imag.tolist(), strict=True))
    with ProcessPoolExecutor(max_workers=workers) as pool:
        out = np.array(list(pool.map(_arb_pair, pairs, chunksize=256)))
    return complex_points(out[:, 0], out[:, 1]), complex_points(out[:, 2], out[:, 3])


def dense(cache: Path = CACHE) -> tuple[Complex, Complex, Complex]:
    """The dense map ``(z, w, dw)``, computed on first use and cached."""
    if cache.exists():
        data = np.load(cache)
        return data["z"], data["w"], data["dw"]
    z = dense_grid()
    w, dw = compute(z)
    cache.parent.mkdir(parents=True, exist_ok=True)
    np.savez_compressed(cache, z=z, w=w, dw=dw)
    return z, w, dw
```

```python
"""The error metrics of spec §6.2."""

from __future__ import annotations

import numpy as np
from numpy.typing import NDArray

#: Values whose true K = Re w is below the smallest normal double are exempt (spec §6.2).
TINY = float(np.finfo(np.float64).tiny)


def value_error(w: NDArray[np.complex128], w_ref: NDArray[np.complex128]) -> NDArray[np.float64]:
    """|K − K_ref| / K_ref, with K = Re w; 0 where K_ref < TINY."""
    k = w_ref.real
    with np.errstate(all="ignore"):
        err = np.abs(w.real - k) / k
    return np.where(k >= TINY, err, 0.0)


def derivative_error(
    dw: NDArray[np.complex128], dw_ref: NDArray[np.complex128]
) -> NDArray[np.float64]:
    """max(|ΔRe w′|, |ΔIm w′|) / |w′_ref|: K_x = Re w′ and K_y = −Im w′, each relative to |w′|."""
    with np.errstate(all="ignore"):
        return np.maximum(np.abs(dw.real - dw_ref.real), np.abs(dw.imag - dw_ref.imag)) / np.abs(
            dw_ref
        )
```

```python
"""Candidate approximations of the Faddeeva function w(z) = exp(-z²) erfc(-iz), for Im z ≥ 0.

Every candidate returns ``(w, dw)``: w(z) and its derivative w′(z), both from the same formula
(the derivative of the approximation itself, never the identity w′ = −2zw + 2i/√π), as
complex128 arrays shaped like ``z``.
"""

from __future__ import annotations

from functools import cache
from math import factorial

import numpy as np
from numpy.typing import NDArray
from scipy.special import dawsn

Complex = NDArray[np.complex128]

INV_SQRT_PI = 0.5641895835477562869480795

# sasktran2's 8-pole J-pole constants (rust/sasktran2-rs/src/math/errorfunctions/optimized.rs).
_JPOLE_B = np.array(
    [
        0.00383968430671409 - 0.0119854387180615j,
        -0.321597857664957 - 0.218883985607935j,
        2.55515264319988 + 0.613958600684469j,
        -2.73739446984183 + 5.69007914897806j,
        0.00383968430671409 + 0.0119854387180615j,
        -0.321597857664957 + 0.218883985607935j,
        2.55515264319988 - 0.613958600684469j,
        -2.73739446984183 - 5.69007914897806j,
    ]
)
_JPOLE_C = np.array(
    [
        2.51506776338386 - 1.60713668042405j,
        -1.68985621846204 - 1.66471695485661j,
        0.981465428659098 - 1.70017951305004j,
        -0.322078795578047 - 1.71891780447016j,
        -2.51506776338386 - 1.60713668042405j,
        1.68985621846204 - 1.66471695485661j,
        -0.981465428659098 - 1.70017951305004j,
        0.322078795578047 - 1.71891780447016j,
    ]
)


def jpole8(z: Complex) -> tuple[Complex, Complex]:
    """sasktran2's 8-pole approximation (the baseline): w ≈ −(i/√π) Σⱼ bⱼ/(z − cⱼ)."""
    d = z[..., None] - _JPOLE_C
    w = (-1j * INV_SQRT_PI) * np.sum(_JPOLE_B / d, axis=-1)
    dw = (1j * INV_SQRT_PI) * np.sum(_JPOLE_B / d**2, axis=-1)
    return w, dw


@cache
def weideman_coefficients(n: int) -> tuple[NDArray[np.float64], float]:
    """Weideman (1994) coefficients ``a`` (highest power first, for np.polyval) and L."""
    m = 2 * n
    k = np.arange(-m + 1, m)
    big_l = np.sqrt(n / np.sqrt(2.0))
    t = big_l * np.tan(k * np.pi / (2 * m))
    f = np.concatenate([[0.0], np.exp(-(t**2)) * (big_l**2 + t**2)])
    a = np.real(np.fft.fft(np.fft.fftshift(f))) / (2 * m)
    return a[1 : n + 1][::-1].copy(), float(big_l)


def weideman(z: Complex, n: int) -> tuple[Complex, Complex]:
    """Weideman's rational approximation with n terms:
    w = 2 p(Z)/(L − iz)² + 1/(√π (L − iz)), Z = (L + iz)/(L − iz)."""
    a, big_l = weideman_coefficients(n)
    d = big_l - 1j * z
    zz = (big_l + 1j * z) / d
    p = np.polyval(a, zz)
    dp = np.polyval(np.polyder(a), zz)
    w = 2 * p / d**2 + INV_SQRT_PI / d
    dw = 2 * dp * (2j * big_l / d**2) / d**2 + 4j * p / d**3 + 1j * INV_SQRT_PI / d**2
    return w, dw


def laplace_cf(z: Complex, depth: int) -> tuple[Complex, Complex]:
    """Laplace continued fraction truncated after ``depth`` levels:
    w ≈ (i/√π) / (z − ½/(z − 1/(z − (3/2)/(z − …)))). Depth 0 is the Lorentzian i/(√π z);
    depth 1 is Humlíček's region-I formula iz/(√π (z² − ½))."""
    f = np.array(z, dtype=np.complex128, copy=True)
    fp = np.ones_like(f)
    for k in range(depth, 0, -1):
        a = k / 2
        f, fp = z - a / f, 1 + a * fp / f**2
    return 1j * INV_SQRT_PI / f, -1j * INV_SQRT_PI * fp / f**2


def gauss_cf(z: Complex, depth: int) -> tuple[Complex, Complex]:
    """exp(−z²) plus the continued fraction: keeps the Gaussian core that the asymptotic
    expansion lacks, for small y and moderate |x|."""
    g = np.exp(-(z * z))
    w, dw = laplace_cf(z, depth)
    return w + g, dw - 2 * z * g


def small_y_taylor(z: Complex, order: int) -> tuple[Complex, Complex]:
    """Taylor series in iy about the real axis, to (iy)^order:
    w(x + iy) ≈ Σₖ (iy)ᵏ w⁽ᵏ⁾(x)/k!, with w(x) = exp(−x²) + (2i/√π) D(x) (D: Dawson) and
    w⁽ᵏ⁺¹⁾ = −2x w⁽ᵏ⁾ − 2k w⁽ᵏ⁻¹⁾."""
    x = z.real
    iy = 1j * z.imag
    w0 = np.exp(-(x * x)) + 2j * INV_SQRT_PI * dawsn(x)
    derivs = [w0, -2 * x * w0 + 2j * INV_SQRT_PI]
    for k in range(1, order + 1):
        derivs.append(-2 * x * derivs[k] - 2 * k * derivs[k - 1])
    w = np.zeros_like(w0)
    dw = np.zeros_like(w0)
    for k in range(order + 1):
        c = iy**k / factorial(k)
        w = w + c * derivs[k]
        dw = dw + c * derivs[k + 1]
    return w, dw


#: Every method the search may use, by key ``(name, parameter)``.
METHODS = {
    "jpole8": lambda z, _: jpole8(z),
    "weideman": weideman,
    "cf": laplace_cf,
    "gauss_cf": gauss_cf,
    "taylor": small_y_taylor,
}


def evaluate(key: tuple[str, int], z: Complex) -> tuple[Complex, Complex]:
    """Evaluate the method ``key`` (for example ``("weideman", 32)``) at ``z``."""
    name, param = key
    return METHODS[name](z, param)
```

**Files:**

- Test: `prototypes/faddeeva/tests/{test_search.py, test_occupancy.py}`

**Interfaces:**
- Consumes: from Task 4, `candidates.evaluate`, `metrics.value_error`, `metrics.derivative_error`, and from `reference`: `load_committed`, `dense`, `complex_points`, `arb_w` and `REPO`.
- Produces:
  - `search.Region`, `search.assign`, `search.ErrorTable`, `search.measure`, `search.search`, `search.cost`, `search.BASELINES` and `search.TARGET_VALUE`/`TARGET_DERIVATIVE`/`MARGIN`;
  - `occupancy.workload_points()`;
  - the CLI `python -m faddeeva_prototype report`;
  - the report files;
  - the decision record that phase 1a implements.

How the search works:
1. `ErrorTable` computes, once, the value and derivative error of every method variant (`KEYS`: J-pole, Weideman 24/32/40, CF depth 0 to 16, exp + CF depth 0 to 16, Taylor order 1 to 5) at every evaluation point. That is about 150 000 points, from the committed grid plus the dense Arb map.
2. A composite is an ordered list of `Region`s; the first region that matches a point decides its method.
3. `build` fills one template:
   1. exp + CF for y ≤ y_g and x_g ≤ |x| < 27;
   2. CF bands for |z| ≥ r_core;
   3. an optional Taylor region for y ≤ y_t and |x| < x_g;
   4. a Weideman core.

   Each region gets the smallest depth that meets **half** of each target. The factor of two is margin for the Rust port.
4. `search` tries every combination of `GRID` and ranks the valid composites by expected cost. The cost is a flop-count proxy, weighted by where the grid points of the representative atmospheric lines (`occupancy.py`) fall.

```python
"""Where a line's window puts its grid points in (|x|, y): the cost weights of the search.

Six representative lines of the primary workload (spec §10.1): an O₂ A-band and a CO₂ 1.6 µm
line, each at the surface, near 30 km and near 65 km, on a 0.005 cm⁻¹ grid with the default
25 cm⁻¹ window. Each line contributes equally.
"""

from __future__ import annotations

from dataclasses import dataclass

import numpy as np
from numpy.typing import NDArray

from faddeeva_prototype.reference import complex_points

K_B = 1.380649e-23  # J/K
N_A = 6.02214076e23  # 1/mol
C = 299792458.0  # m/s

SPACING_CMINV = 0.005
WIDTH_CMINV = 25.0


@dataclass(frozen=True)
class Line:
    """A representative line: centre (cm⁻¹), isotopologue mass (g/mol), γ_air (cm⁻¹/atm), n_air."""

    name: str
    centre: float
    mass: float
    gamma_air: float
    n_air: float


LINES = (
    Line("O2 A-band", 13100.0, 31.98983, 0.045, 0.72),
    Line("CO2 1.6 um", 6300.0, 43.98983, 0.070, 0.75),
)
#: (temperature K, pressure Pa): the surface, about 30 km, about 65 km.
CONDITIONS = ((250.0, 101325.0), (225.0, 1000.0), (200.0, 10.0))


def doppler_width(centre: float, temperature: float, mass: float) -> float:
    """Doppler 1/e half width σ_D = (ν₀/c) √(2 k_B T / m), in cm⁻¹."""
    return centre / C * np.sqrt(2 * K_B * temperature * N_A * 1e3 / mass)


def lorentz_width(line: Line, temperature: float, pressure: float) -> float:
    """Air-broadened half width (296/T)^n γ_air p, in cm⁻¹ (p in atm)."""
    return line.gamma_air * (296.0 / temperature) ** line.n_air * pressure / 101325.0


def workload_points() -> NDArray[np.complex128]:
    """|x| + iy of every grid point in the windows of the representative lines."""
    n = round(WIDTH_CMINV / SPACING_CMINV)
    offsets = np.arange(-n, n + 1) * SPACING_CMINV
    out = []
    for line in LINES:
        for temperature, pressure in CONDITIONS:
            sd = doppler_width(line.centre, temperature, line.mass)
            y = lorentz_width(line, temperature, pressure) / sd
            out.append(complex_points(np.abs(offsets) / sd, np.full(offsets.size, y)))
    return np.concatenate(out)
```

Create `prototypes/faddeeva/faddeeva_prototype/search.py`:

```python
"""Composite (region-switched) algorithms, their errors and costs, and the search over them.

A composite is an ordered list of regions; each point of the (|x|, y) plane uses the method of
the first region that contains it, and the last region contains every point. The errors of
every method at every evaluation point are computed once (`ErrorTable`), so a composite's
errors are a selection from that table.
"""

from __future__ import annotations

import itertools
import math
from dataclasses import asdict, dataclass

import numpy as np
from numpy.typing import NDArray

from faddeeva_prototype.candidates import evaluate
from faddeeva_prototype.metrics import derivative_error, value_error

Key = tuple[str, int]

TARGET_VALUE = 1e-6  # spec §6.3, Fast tier
TARGET_DERIVATIVE = 1e-5
#: The prototype must meet half of each target, leaving room for the Rust port's rounding.
MARGIN = 0.5

MAX_DEPTH = 16
#: The method variants the search draws on.
KEYS: tuple[Key, ...] = (
    ("jpole8", 0),
    *(("weideman", n) for n in (24, 32, 40)),
    *(("cf", d) for d in range(MAX_DEPTH + 1)),
    *(("gauss_cf", d) for d in range(MAX_DEPTH + 1)),
    *(("taylor", k) for k in range(1, 6)),
)

#: Cost proxy in flop-equivalents per point, value and derivative together: a complex
#: multiply-add counts 8, a complex division 12, a complex exp 40, Dawson's function 30.
#: It ranks composites; real costs are measured in Rust in phase 1a.
COST_BASE = {"jpole8": 240, "weideman": 56, "cf": 24, "gauss_cf": 94, "taylor": 70}
COST_STEP = {"jpole8": 0, "weideman": 16, "cf": 40, "gauss_cf": 40, "taylor": 24}


def cost(key: Key) -> float:
    """The cost proxy of a method variant."""
    name, param = key
    return COST_BASE[name] + COST_STEP[name] * param


@dataclass(frozen=True)
class Region:
    """Points with y ≤ y_max, x_min ≤ |x| < x_max, r_min ≤ |z| < r_max and |x| + y ≥ s_min."""

    name: str
    method: Key
    y_max: float = math.inf
    x_min: float = 0.0
    x_max: float = math.inf
    r_min: float = 0.0
    r_max: float = math.inf
    s_min: float = 0.0

    def contains(self, z: NDArray[np.complex128]) -> NDArray[np.bool_]:
        x, y, r = np.abs(z.real), z.imag, np.abs(z)
        return (
            (y <= self.y_max)
            & (x >= self.x_min)
            & (x < self.x_max)
            & (r >= self.r_min)
            & (r < self.r_max)
            & (x + y >= self.s_min)
        )


def assign(regions: list[Region], z: NDArray[np.complex128]) -> NDArray[np.intp]:
    """The index of the first region containing each point; every point must be covered."""
    index = np.full(z.shape, -1, dtype=np.intp)
    for i, region in enumerate(regions):
        index[(index < 0) & region.contains(z)] = i
    if np.any(index < 0):
        raise ValueError("the regions do not cover every point; end with a catch-all region")
    return index


class ErrorTable:
    """Value and derivative errors of every method variant at every evaluation point."""

    def __init__(
        self,
        z: NDArray[np.complex128],
        w_ref: NDArray[np.complex128],
        dw_ref: NDArray[np.complex128],
        keys: tuple[Key, ...] = KEYS,
    ) -> None:
        self.z = z
        self.value: dict[Key, NDArray[np.float64]] = {}
        self.derivative: dict[Key, NDArray[np.float64]] = {}
        for key in keys:
            with np.errstate(all="ignore"):
                w, dw = evaluate(key, z)
            self.value[key] = value_error(w, w_ref)
            self.derivative[key] = derivative_error(dw, dw_ref)

    def worst(self, key: Key, mask: NDArray[np.bool_]) -> tuple[float, float]:
        """The largest value and derivative errors of ``key`` over ``mask`` (NaN counts as ∞)."""
        if not mask.any():
            return 0.0, 0.0
        v = self.value[key][mask]
        d = self.derivative[key][mask]
        worst_v = math.inf if np.isnan(v).any() else float(v.max())
        worst_d = math.inf if np.isnan(d).any() else float(d.max())
        return worst_v, worst_d


def meets(errors: tuple[float, float]) -> bool:
    """Whether the errors meet both targets with the margin."""
    return errors[0] <= MARGIN * TARGET_VALUE and errors[1] <= MARGIN * TARGET_DERIVATIVE


def minimal_parameter(
    table: ErrorTable, name: str, mask: NDArray[np.bool_], params: range
) -> int | None:
    """The smallest parameter of method ``name`` that meets the targets on ``mask``."""
    for p in params:
        if meets(table.worst((name, p), mask)):
            return p
    return None


@dataclass
class Result:
    """A composite with its measured errors and expected cost."""

    regions: list[Region]
    region_errors: list[tuple[float, float]]
    max_value_error: float
    max_derivative_error: float
    expected_cost: float
    occupancy: list[float]

    def to_json(self) -> dict:
        return {
            "regions": [
                {
                    **asdict(r),
                    "method": list(r.method),
                    "max_value_error": e[0],
                    "max_derivative_error": e[1],
                    "occupancy": o,
                }
                for r, e, o in zip(self.regions, self.region_errors, self.occupancy, strict=True)
            ],
            "max_value_error": self.max_value_error,
            "max_derivative_error": self.max_derivative_error,
            "expected_cost": self.expected_cost,
        }


def measure(regions: list[Region], table: ErrorTable, workload: NDArray[np.complex128]) -> Result:
    """Errors over the evaluation points and cost over the workload points of a composite."""
    index = assign(regions, table.z)
    errors = [table.worst(r.method, index == i) for i, r in enumerate(regions)]
    load = assign(regions, workload)
    occupancy = [float(np.mean(load == i)) for i in range(len(regions))]
    return Result(
        regions=regions,
        region_errors=errors,
        max_value_error=max(e[0] for e in errors),
        max_derivative_error=max(e[1] for e in errors),
        expected_cost=sum(o * cost(r.method) for r, o in zip(regions, occupancy, strict=True)),
        occupancy=occupancy,
    )


BASELINES: dict[str, list[Region]] = {
    "jpole8 (sasktran2)": [Region("all", ("jpole8", 0))],
    "hum1wei24 (HAPI)": [
        Region("Humlicek I", ("cf", 1), s_min=15.0),
        Region("Weideman 24", ("weideman", 24)),
    ],
    "Weideman 32": [Region("all", ("weideman", 32))],
    "Weideman 40": [Region("all", ("weideman", 40))],
}

#: Band edges in |z| for the continued fraction; each band gets its own minimal depth.
BAND_EDGES = (8.0, 10.0, 12.0, 15.0, 20.0, 30.0, 50.0, 100.0, 300.0, 1000.0, 3000.0)
#: The Gaussian term exp(−x²) underflows beyond |x| = 27.
GAUSS_X_MAX = 27.0


def build(
    table: ErrorTable,
    y_gauss: float,
    x_gauss: float,
    r_core: float,
    core: Key,
    taylor: tuple[float, int] | None,
) -> list[Region] | None:
    """The composite of one template point, with minimal depths; None if a region fails.

    Regions, first match wins: (1) exp(−z²) + continued fraction for y ≤ y_gauss and
    x_gauss ≤ |x| < 27; (2) continued-fraction bands for |z| ≥ r_core; (3) optionally a
    small-y Taylor series of order k for y ≤ y_taylor and |x| < x_gauss; (4) the core method.
    """
    z = table.z
    taken = np.zeros(z.shape, dtype=bool)
    regions: list[Region] = []

    def add(region_without_method: Region, name: str, params: range) -> bool:
        mask = ~taken & region_without_method.contains(z)
        p = minimal_parameter(table, name, mask, params)
        if p is None:
            return False
        regions.append(Region(**{**asdict(region_without_method), "method": (name, p)}))
        taken[mask] = True
        return True

    depths = range(MAX_DEPTH + 1)
    gauss = Region("exp + CF", ("gauss_cf", 0), y_max=y_gauss, x_min=x_gauss, x_max=GAUSS_X_MAX)
    if not add(gauss, "gauss_cf", depths):
        return None
    edges = [r_core, *(e for e in BAND_EDGES if e > r_core), math.inf]
    for lo, hi in itertools.pairwise(edges):
        band = Region(f"CF |z| in [{lo:g}, {hi:g})", ("cf", 0), r_min=lo, r_max=hi)
        if not add(band, "cf", depths):
            return None
    if taylor is not None:
        y_taylor, order = taylor
        small = Region("Taylor", ("taylor", order), y_max=y_taylor, x_max=x_gauss)
        if not add(small, "taylor", range(order, order + 1)):
            return None
    core_region = Region(f"{core[0]} {core[1]}", core)
    if not meets(table.worst(core, ~taken)):
        return None
    regions.append(core_region)
    return regions


GRID = {
    "y_gauss": (0.01, 0.1, 0.5),
    "x_gauss": (4.0, 5.0, 6.0),
    "r_core": (8.0, 10.0, 12.0, 15.0),
    "core": (("weideman", 24), ("weideman", 32), ("weideman", 40)),
    "taylor": (None, (1e-3, 2), (1e-3, 3), (1e-2, 3), (1e-2, 4)),
}


def search(table: ErrorTable, workload: NDArray[np.complex128]) -> list[Result]:
    """Every composite of the template grid that meets the targets, cheapest first."""
    results = []
    for values in itertools.product(*GRID.values()):
        regions = build(table, *values)
        if regions is not None:
            results.append(measure(regions, table, workload))
    return sorted(results, key=lambda r: r.expected_cost)
```

```python
"""``python -m faddeeva_prototype report``: measure the baselines, search, and write the report."""

from __future__ import annotations

import argparse
import json
import sys
from pathlib import Path

import numpy as np

from faddeeva_prototype import occupancy, reference, search

DOCS = reference.REPO / "docs" / "validation"
DEFAULT_JSON = DOCS / "data" / "faddeeva_prototype.json"
DEFAULT_TABLE = DOCS / "faddeeva-prototype-table.md"


def _fmt(v: float) -> str:
    return f"{v:.1e}"


def table_markdown(baselines: dict[str, search.Result], results: list[search.Result]) -> str:
    lines = [
        "| Algorithm | Max value error | Max derivative error | Expected cost |",
        "|---|---|---|---|",
    ]
    for name, r in baselines.items():
        lines.append(
            f"| {name} | {_fmt(r.max_value_error)} | {_fmt(r.max_derivative_error)} "
            f"| {r.expected_cost:.0f} |"
        )
    if results:
        best = results[0]
        lines += [
            f"| **Selected composite** | {_fmt(best.max_value_error)} "
            f"| {_fmt(best.max_derivative_error)} | {best.expected_cost:.0f} |",
            "",
            "Regions of the selected composite (first match wins):",
            "",
            "| Region | Method | Max value error | Max derivative error | Workload share |",
            "|---|---|---|---|---|",
        ]
        for region, errors, share in zip(
            best.regions, best.region_errors, best.occupancy, strict=True
        ):
            method = f"{region.method[0]} {region.method[1]}"
            lines.append(
                f"| {region.name} | {method} | {_fmt(errors[0])} | {_fmt(errors[1])} "
                f"| {share:.2%} |"
            )
    return "\n".join(lines) + "\n"


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="faddeeva_prototype")
    sub = parser.add_subparsers(dest="command", required=True)
    rep = sub.add_parser("report", help="measure, search and write the report")
    rep.add_argument("--json", type=Path, default=DEFAULT_JSON)
    rep.add_argument("--table", type=Path, default=DEFAULT_TABLE)
    args = parser.parse_args(argv)

    zc, wc, dwc = reference.load_committed()
    zd, wd, dwd = reference.dense()
    z, w, dw = (np.concatenate(p) for p in ((zc, zd), (wc, wd), (dwc, dwd)))
    table = search.ErrorTable(z, w, dw)
    workload = occupancy.workload_points()

    baselines = {
        name: search.measure(regions, table, workload) for name, regions in search.BASELINES.items()
    }
    results = search.search(table, workload)
    report = {
        "targets": {
            "value": search.TARGET_VALUE,
            "derivative": search.TARGET_DERIVATIVE,
            "margin": search.MARGIN,
        },
        "evaluation_points": {"committed": int(zc.size), "dense": int(zd.size)},
        "workload_points": int(workload.size),
        "baselines": {name: r.to_json() for name, r in baselines.items()},
        "valid_composites": len(results),
        "selected": results[0].to_json() if results else None,
        "runners_up": [r.to_json() for r in results[1:5]],
    }
    args.json.parent.mkdir(parents=True, exist_ok=True)
    args.json.write_text(json.dumps(report, indent=2, sort_keys=True) + "\n", encoding="utf-8")
    args.table.write_text(table_markdown(baselines, results), encoding="utf-8")
    print(table_markdown(baselines, results), file=sys.stderr)
    if not results:
        print("No composite meets the targets: see the baselines in the report.", file=sys.stderr)
        return 1
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```markdown
| Quantity | Unit |
|---|---|
| Wavenumber | cm⁻¹ |

Line parameters follow HITRAN units and conventions:
```

````markdown
# Choosing the Fast-tier Faddeeva algorithm

Every Voigt line shape in absrbrs is the real part of the Faddeeva function
w(z) = exp(−z²) erfc(−iz), at z = x + iy with x = (ν − ν₀′)/σ_D and y = γ_L/σ_D. The Fast
accuracy tier must hold the error of K = Re w to 1 × 10⁻⁶ relative, and that of each part of
w′(z) to 1 × 10⁻⁵ relative to |w′|, over the whole domain: y from 0 to 10⁶ and |x| up to 10⁸.
Values below the smallest normal double are exempt.

Phase 0 chose the algorithm by measurement. The prototype in `prototypes/faddeeva/` evaluates
candidate approximations, each returning w and the derivative of its own formula:

- Weideman's rational approximation with 24, 32 or 40 terms;
- the Laplace continued fraction truncated at depth 0 to 16 (depth 0 is the Lorentzian and
  depth 1 Humlíček's region-I formula);
- exp(−z²) plus the continued fraction, for small y and moderate |x|;
- a Taylor series in y about the real axis, using Dawson's integral;
- sasktran2's 8-pole approximation, and HAPI's hum1wei24, as baselines.

It measures them against Arb at about 150 000 points: the committed reference grid
(`reference/data/faddeeva.jsonl`) and a denser map computed with Arb. A search over
region-switched composites then picks the cheapest one that meets half of each target, leaving
room for the Rust implementation's rounding. Cost is a flop-count proxy, weighted by where the
grid points of representative atmospheric lines fall in the (|x|, y) plane: O₂ A-band and CO₂
1.6 µm lines at the surface, near 30 km and near 65 km, on a 0.005 cm⁻¹ grid with a 25 cm⁻¹
window. Most of those points lie far from the line centre, where a shallow continued fraction
is accurate and cheap.

The maximum errors below are relative, as defined above. They are enormous for the baselines
because, far into the wings at zero or very low pressure, K is tiny (exp(−x²) or y/x²) and a
fixed-accuracy approximation's absolute error swamps it.
````
